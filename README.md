# AURA BLOOM • ROSEVERSE Botanical Kinetic Atelier

A luxury, ultra-high-definition 2026 web application featuring a **300-frame HTML5 Canvas 2D LERP motion engine**, 3D perspective depth cosmos, spatial Web Audio synthesizer, transparent glass navigation bar, AI sales & business assistant, and eye comfort resolution scaling.

## 🚀 Live Demo & Deployment

This project is pre-configured with `vercel.json` for one-click deployment on **Vercel**.

### Deploy to Vercel
1. Import this GitHub repository (`https://github.com/nandkishorsinha78-ui/ROSEVERSE-WEBSITE.git`) into [Vercel](https://vercel.com).
2. Framework Preset: Select **Other** (Static Site).
3. Click **Deploy**. Vercel will automatically serve all 300 HD frames, assets, and pages over a global CDN.

## 🛠️ Features

* **300-Frame HTML5 Canvas Motion Engine**: 60FPS sub-frame step linear interpolation (`requestAnimationFrame`) with zero lag or frame skipping.
* **Scroll Animation Heading Overlay**: "ROSEVERSE • THE LOVE OF INDIANS" with a soft emerald-sage product tone gradient and 30% scroll fade-away.
* **Transparent Navigation Bar**: Fixed glassmorphic navigation bar with smooth section scrolling (`#hero`, `#about`, `#kinetic-studio`, `#collection`, `#masterclass`, `#boutique`, `#process`, `#products`, `#faq`) and active ScrollSpy highlighting.
* **3D Perspective Particle Cosmos**: Z-axis camera space particle depth layer with real-time magnetic mouse parallax.
* **Ethical AI Sales & Business Assistant**: Glassmorphic floating widget providing transparent advice, project recommendations, and instant consultation booking.
* **Eye Comfort & Resolution Scaling**: 90% default viewport scale with instant 100%, 125% Eye Comfort mode.
